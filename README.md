# Libuno — Public Library

A multi-page public library website with Home, About, Blog and Contact pages, built with HTML, CSS and Bootstrap.

**Live demo:** https://muhammadrakib2299.github.io/Libuno-public-library/

## Sections / Features

- Four pages that share a collapsible Bootstrap 5 navbar
- Home: a full-width banner, a "Most Popular" grid of eight books, an About block with an embedded YouTube video, and "Let's Know" info boxes (Ask a Librarian, Innovations, Join the Library, Help)
- About: an overview of the library's sections (Preamble, Bangabandhu Corner, Library Cafe, Kabi Nazrul EduPlex)
- Blog: a "Work plan - 2022" list
- Contact: a "Get in Touch" form (first name, last name, email, subject) with required fields

## Built with

HTML5 · CSS3 (CSS Grid, Flexbox) · Bootstrap 5.2.2 (CDN, used for the navbar)

## What I practised

- Building a multi-page site with shared navigation
- The Bootstrap navbar with a collapse toggle for small screens
- A four-column CSS Grid for the book list, plus embedding an `iframe` video
- A mobile media query for the contact form

## Run locally

Open `index.html` in a browser.
